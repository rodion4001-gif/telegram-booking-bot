# Telegram-бот для записи клиентов

Бот принимает заявки на приём прямо в Telegram: клиент выбирает услугу, день и время, оставляет телефон, а владелец сразу получает уведомление. Подходит для барбершопов, салонов, мастеров, репетиторов и любых услуг по записи.

## Возможности

- Пошаговая запись: имя → услуга → день → время → телефон → подтверждение
- Выбор даты и времени кнопками, ввод ошибочной даты невозможен
- Защита от двойной записи: занятое время не показывается
- Проверка и единый формат телефона (`+7 999 123-45-67`), поддержка кнопки «Отправить мой номер»
- Уведомление владельцу в Telegram о каждой новой заявке
- Все заявки сохраняются в `bookings.csv` (открывается в Excel)
- Отмена записи в любой момент командой `/cancel`

## Технологии

Python 3.10+, [aiogram 3](https://docs.aiogram.dev/), python-dotenv

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   source .venv/bin/activate     # macOS / Linux
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и заполните:
   ```
   BOT_TOKEN=токен_от_BotFather
   OWNER_ID=ваш_числовой_Telegram_ID
   ```
5. Запустите:
   ```
   python bot.py
   ```

## Настройка под бизнес

В начале `bot.py` меняются:

| Параметр | Что делает |
|---|---|
| `SERVICES` | список услуг |
| `TIME_SLOTS` | часы приёма |
| `DAYS_AHEAD` | на сколько дней вперёд можно записаться |

## Структура

```
bot.py            код бота
requirements.txt  зависимости
.env.example      пример настроек (сам .env в репозиторий не попадает)
bookings.csv      заявки (создаётся при первой записи)
```

## Возможные доработки

Выходные и перерывы, напоминания клиенту за день до записи, отмена записи самим клиентом, база данных вместо CSV, панель администратора, оплата.
